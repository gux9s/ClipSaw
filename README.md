# Lipps by huakly — ссылка на YouTube → пачка вертикальных шортсов

Только нарезка сериалов/фильмов. Кидаешь ссылку на серию (Универ и т.п.) —
получаешь вертикальные клипы 9:16 с субтитрами и оценкой виральности.

## Запуск

```bash
./run.sh
```

Открой http://127.0.0.1:5003

## Пайплайн

1. Скачивание ≤1080p H.264
2. Детекция сцен (PySceneDetect, склейка коротких)
3. Транскрибация (faster-whisper, локально)
4. LLM-скоринг моментов (Gemini, ключ бесплатный) или эвристика
5. Привязка границ к сценам + разброс по видео (diversity)
6. Вертикаль: размытый фон / трек лица / мгновенная нарезка
7. Субтитры с пословной подсветкой, анти-детект без зеркала (опция)

## Режимы

- Размытый фон — как у кинонарезок, для сериалов лучший
- Трек лица — крупный план говорящего
- Только нарезка — мгновенный copy-cut без обработки
- Свои таймкоды — строки «мм:сс-мм:сс», режет точно по ним

## Геймплей-низ: «шары в круге»

Процедурный геймплей (порт `laiprogramming/bouncing_balls`): чёрный фон,
оранжевое кольцо с вращающимся разрывом, пастельные шарики под гравитацией.
Каждый рендер — новый ролик, поэтому в настройках есть режим
**balls (новый каждый клип)**: на клип берётся случайный файл из `gameplay/`.

```bash
python3 balls_sim.py --count 6          # пачка вариантов в gameplay/
python3 balls_sim.py --duration 45 --seed 7 --counter
```

## Статичный баннер

Готовая белая плашка ShardVPN — `assets/shardvpn_white_5min_greenscreen.mp4`
(780×200, хромакей выбивается на лету, файл лежит 5 минут статикой). Висит
весь ролик внизу, на экране показывается крупнее нативной — ×1.238
(канва 966×248, белая плашка в ней ≈746×135). Для геймплея «шары в круге»
она ложится поверх низа кадра — ровно под кругом, без ужимания геймплея.
Для остальных геймплеев работает старая «полка» под низом (355px).

Каждый рендер плашка чуть-чуть другая (`_bn_unique_vf()`): яркость
±1%, контраст/насыщенность ±1%, тон ±0.35°, лёгкое паттерное зерно,
плюс зум ±0.25%, сдвиг ±5/±3px и альфа 0.955…1.0. Глазом не видно,
но баннерная область не совпадает пиксель-в-пиксель между клипами пачки.

Меняется в настройках («Баннер») или в `config.json` → `banner_file`.
