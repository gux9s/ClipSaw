# ClipSaw — ссылка на YouTube → пачка вертикальных шортсов

Только нарезка сериалов/фильмов. Кидаешь ссылку на серию (Универ и т.п.) —
получаешь вертикальные клипы 9:16 с субтитрами и оценкой виральности.

## Запуск

```bash
./run.sh
```

Открой http://127.0.0.1:5003

## Пайплайн

1. Скачивание ≤1080p H.264
2. Детекция сцен (PySceneDetect, склейка коротких)
3. Транскрибация (faster-whisper, локально)
4. LLM-скоринг моментов (Gemini, ключ бесплатный) или эвристика
5. Привязка границ к сценам + разброс по видео (diversity)
6. Вертикаль: размытый фон / трек лица / мгновенная нарезка
7. Субтитры с пословной подсветкой, анти-детект без зеркала (опция)

## Режимы

- Размытый фон — как у кинонарезок, для сериалов лучший
- Трек лица — крупный план говорящего
- Только нарезка — мгновенный copy-cut без обработки
- Свои таймкоды — строки «мм:сс-мм:сс», режет точно по ним
